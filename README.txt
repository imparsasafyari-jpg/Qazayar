نصب «قضای نماز» روی اندروید
=============================
این پوشه یک PWA کامل است (اپ نصب‌شدنی). برای نصب باید روی یک آدرس https قرار بگیرد:

روش ۱ (ساده‌تر، رایگان): Netlify Drop
  ۱. وارد app.netlify.com/drop شوید (ثبت‌نام رایگان).
  ۲. کل پوشه (یا فایل zip) را روی صفحه بکشید و رها کنید.
  ۳. آدرس سایت را در کروم گوشی باز کنید.

روش ۲: GitHub Pages
  ۱. یک repository جدید بسازید و همه‌ی فایل‌های این پوشه را آپلود کنید.
  ۲. Settings ← Pages ← Branch: main را فعال کنید.

بعد از باز کردن آدرس در کروم اندروید:
  منوی ⋮ ← «Install app» (یا «Add to Home screen») ← تأیید.
  آیکون ذوالفقار روی صفحه‌ی اصلی می‌آید و اپ بدون نوار مرورگر و آفلاین باز می‌شود.

نکات:
- اطلاعات در حافظه‌ی همان مرورگر/اپ نصب‌شده ذخیره می‌شود. برای انتقال داده از نسخه‌ی Claude:
  تنظیمات ← «کپی کردن پشتیبان» و در نسخه‌ی نصب‌شده ← «بازیابی از پشتیبان».
- پرسش‌وپاسخ هوشمند احکام فقط داخل نسخه‌ی Claude کار می‌کند؛ در نسخه‌ی نصب‌شده بخش «احکام پرتکرار» در دسترس است.
